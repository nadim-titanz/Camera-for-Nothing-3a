# FEATURE STATUS — Nothing Camera Pro

| Feature | Status | Hardware / API Dependency | Verification Status | Known Limitations / Notes |
|---|---|---|---|---|
| **Main Camera Experience (Launch Screen)** | Implemented (Phase 1–6) | Jetpack Compose + Navigation Compose (`camera` start route) | Compiled & Robolectric navigation verified | Hardware Diagnostics moved to `Settings -> Developer Tools -> Camera Diagnostics` |
| **Live Camera Viewfinder & Gestures** | Implemented (Phase 1) | CameraX `PreviewView` + `ViewPort` + `CameraEffect` | Compiled | Supports `4:3`, `16:9`, `1:1`, `FULL`, `3x3`/`4x4` grid, gyro horizon level, pinch zoom, horizontal mode swipe |
| **Photo Capture & Scoped MediaStore Gallery** | Implemented (Phase 2) | CameraX `ImageCapture` + `MediaStore` (`DCIM/NothingCameraPro`) + `Coil` | Compiled & Gallery flow tested | Zero storage permissions (`READ_MEDIA_*` not requested); includes in-app viewer, share, delete, and post-capture editor |
| **Video Recording Pipeline** | Implemented (Phase 3) | CameraX `VideoCapture` + `Recorder` + `MediaStoreOutputOptions` | Compiled | Dynamic Resolution/FPS menu populated from `Recorder.getVideoCapabilities`; supports pause/resume, torch, stabilization toggle, and `RECORD_AUDIO` graceful fallback |
| **Zoom, Focus, AE/AF Lock, EV & Flash** | Implemented (Phase 4) | `ZoomState`, `FocusMeteringAction`, `ExposureState`, `Camera2Interop` | Compiled | Capability-gated zoom pills (`0.6x` / `1x` / `2x` / `5x`), tap-to-focus, long-press AE/AF lock badge, EV slider, live `ACTIVE_PHYSICAL_ID` telemetry badge |
| **Photo / Video / Portrait Mode Switcher** | Implemented (Phase 5) | CameraX UseCaseGroup + ML Kit Selfie Segmentation (`STREAM_MODE` & `SINGLE_IMAGE_MODE`) | Compiled & Mode switching tested | Live preview GPU bokeh + adjustable `f/1.4–f/16` blur slider + full-resolution feathering composite on capture |
| **Photographic Styles Engine (10 Styles)** | Implemented (Phase 6) | OpenGL ES 2.0 `SurfaceProcessor` + `PhotographicStyleBitmapProcessor` | Unit tested & Compiled | 10 styles (`Natural`, `Vivid`, `Vivid Warm`, `Vivid Cool`, `Rich Contrast`, `Dramatic`, `Warm`, `Cool`, `Matte`, `Black & White`), intensity slider, skin-tone protection, Save Original Copy sidecar & non-destructive post-capture editor |
| **Camera Settings & Developer Diagnostics** | Implemented | `DataStore` Preferences + `Camera2DiagnosticsCollector` | Compiled & Robolectric tested | Includes Grid, Horizon Level, Save Original, Mirror Selfie, RAW (when supported), Video Stabilization, Haptics, and `Developer Tools -> Camera Diagnostics` |
| **Logical Multi-Camera & Auxiliary Lens Discovery** | Confirmed Baseline (`Nothing A059`) | `CameraManager`, `Camera2Interop`, `LOGICAL_MULTI_CAMERA_ACTIVE_PHYSICAL_ID` | On-device public IDs reported (`0`, `1`) | Nothing A059 Android 17 (SDK 37) exposes 2 public IDs (`ID 0` Rear, `ID 1` Front). App queries `ZoomState.minZoomRatio`/`maxZoomRatio` and physical sub-IDs dynamically and never fakes unsupported zoom stops |
